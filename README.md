# Portfolio Website

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS.

## ✨ Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Dark/Light Mode**: Toggle between themes with smooth transitions
- **Smooth Animations**: Built with Framer Motion for engaging user experience
- **Modern Tech Stack**: React 18, TypeScript, Tailwind CSS, and Vite
- **Accessible**: Built with accessibility best practices
- **Fast Performance**: Optimized for speed and SEO

## 🚀 Sections

- **Hero**: Eye-catching introduction with call-to-action
- **About**: Personal information, skills, and technologies
- **Projects**: Filterable portfolio showcase with project details
- **Contact**: Interactive contact form with validation

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Development**: ESLint, Hot Module Replacement

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 🎨 Customization

### Personal Information
- Update `src/components/Hero.tsx` with your name and tagline
- Modify `src/components/About.tsx` with your personal information and skills
- Add your projects in `src/components/Projects.tsx`
- Update contact information in `src/components/Contact.tsx`

### Styling
- Colors and design tokens are configured in Tailwind CSS
- Custom animations can be added using Framer Motion
- Theme configuration is in `src/hooks/useTheme.ts`

### Images
- Replace placeholder images in the projects section
- Add your profile picture to the hero section
- Update favicon and meta tags in `index.html`

## 📱 Responsive Breakpoints

- **Mobile**: < 768px
- **Tablet**: 768px - 1024px
- **Desktop**: > 1024px
